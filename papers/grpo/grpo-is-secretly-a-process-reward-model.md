# GRPO is Secretly a Process Reward Model

> GRPO 是隐藏的 PRM——组内共享前缀天然构成"过程步骤"，标准 GRPO 与 PRM-aware 目标逐项数学等价（Saarland，2025）

## 这篇论文到底在解决什么问题？

GRPO 已经在数学推理和多模态 RL 里被广泛使用（DeepSeek-R1 等），但有一个尴尬的理论空白：**GRPO 只给整个回答一个结果级奖励（outcome reward），那它是怎么做到"过程级"的 credit assignment 的？** 直觉上，结果级奖励无法告诉模型"哪一步对了、哪一步错了"，但实践中 GRPO 训练出的推理链质量确实在逐步提升——这中间一定发生了什么，但没人从理论上说清楚。

为什么以前的分析不行？
- 以往研究把 GRPO 当作"结果奖励 RL"的实例，没有人把它与过程奖励模型（PRM）联系起来；
- 缺少一个能对照的"PRM-aware 目标函数"，无法做严格的数学比较。

这篇论文想改什么：**从理论上证明——在 token 级 policy gradient + 单次更新（μ=1）的设定下，标准 GRPO 的目标函数与一个显式的 PRM-aware 目标函数逐项数学等价。** 换句话说，GRPO 一直在隐式地做细粒度的过程级 credit assignment。

## 他们怎么做的？

**核心 idea：把"组内 G 个回答的共享前缀"定义为"过程步骤"，给每个 token 赋予该前缀下所有轨迹的平均奖励，构造一个 PRM-aware loss，然后证明它与标准 GRPO loss 逐项相等。** 技术流派：RL 理论分析 + 经验验证。

1. **第一步：形式化设定**：token 级 policy gradient（每个 token 的梯度独立），单次更新（μ=1，即每个组只用来做一次梯度更新）——这是 GRPO 的标准训练配置；
2. **第二步：用共享前缀定义过程步骤（process sets）**：组内 G 个轨迹共享的前缀（比如前 10 个 token 完全相同）自然构成一个"过程步骤"——它是所有轨迹共同经过的中间状态；
3. **第三步：构造 PRM-aware 目标**：对共享前缀 λ 内的每个 token，赋予该前缀下所有轨迹的平均奖励 \(r_{mean}(\lambda)\)，得到"给每个过程步骤打分"的显式 PRM 式损失；
4. **第四步：逐项等价证明**：证明该 PRM-aware loss 与标准 GRPO loss **每一项都数学相等**——标准 GRPO 无需任何修改，就已经在做过程级奖励分配；
5. **第五步：经验验证**：在 Qwen 数学推理微调中观察——随着训练推进，组内共享前缀结构越来越丰富（**组大小 36 时几乎 100% 的组存在非平凡过程结构**），模型收敛后倾向于为同一问题生成相似的高质量前缀，说明这个"隐式 PRM"真实存在且活跃。

**暴露的缺陷（Process Step Frequency Flaw）**：等价性成立，但标准 GRPO 中某个过程步骤对梯度的贡献与其频率 \(|\lambda|\) 成正比，这带来两个问题：
- **抑制探索**：高频前缀即使只有微正优势也会被放大强化，模型可能过早收敛到次优路径；
- **阻碍利用**：有价值但低频的轨迹若与低奖励轨迹共享前缀，平均优势可能为负，被连带惩罚。

**修复方案（λ-GRPO）**：用**逆频率 \(|\lambda|^{-1}\)** 缩放每个 token 的贡献，让过程步骤的影响力与其出现频率解耦，平衡各步骤的 credit 分配。

## 效果怎么样？

- **理论贡献**：首次严格证明 GRPO = 隐式 PRM（token 级 + μ=1 设定下逐项等价），把"结果奖励 RL"和"过程奖励"两条看似独立的路线统一到同一谱系；
- **λ-GRPO 实验**：在 **75% 的基准**上优于标准 GRPO，平均提升约 **10%**，且收敛更快；
- **过程结构随训练涌现**：组大小 36 时几乎 100% 的组存在非平凡共享前缀——隐式过程建模是 GRPO 训练的自然产物。

**局限性**：理论等价建立在 token 级 policy gradient + 单次更新（μ=1）的设定上，实际训练中的多次更新、批处理可能偏离该设定；λ-GRPO 的逆频率缩放引入了新的超参数，其最优取值在不同任务上尚需调参。

## 对谁有用？

- 做 **RL 理论 / GRPO 变体改进**的人——"GRPO 隐式做过程 credit assignment"是理解一切 GRPO 变体的新坐标系；
- 综述定位：**Background 中"推理过程优化（3.3）"的理论支柱**——它直接支撑你综述的 thesis：**奖励信号演进是连续谱，不是离散类别**（GRPO 与 PRM 不是两条独立路线）。同时要指出边界：GRPO 的隐式 PRM 是基于"答案正确性驱动的共享前缀"，不是基于"视觉语义结构"——在组合推理场景中，共享前缀可能来自文本模式而非真正的视觉组合理解，这正说明多模态组合推理需要显式视觉对齐奖励（Ground-R1、GRIT、POLIA 等），为你论文的 3.2/3.3 章提供动机。

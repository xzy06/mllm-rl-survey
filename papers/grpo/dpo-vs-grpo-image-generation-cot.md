# Delving into RL for Image Generation with CoT: A Study on DPO vs. GRPO

> DPO vs GRPO：在"自回归图像生成 = 逐 token 推理过程"这个设定下，把两大 RL 算法掰开揉碎对比——DPO 域内更强，GRPO 域外泛化更好，奖励模型的选择还暗藏玄机

## 这篇论文到底在解决什么问题？

DPO（直接偏好优化）和 GRPO（组相对策略优化）是当下给大模型做 RL 训练的两大代表算法，各自有支持者，但**很少有工作在同一个任务上对它们做系统的公平对比**。自回归图像生成恰好是一个理想试验场：它本质上是"逐 token 生成图像代码/序列"的顺序过程，可以看作一种 CoT 推理——任务定义清晰、可验证，且与纯文本推理（如数学）在结构和挑战上不同（图像是连续的、空间关系复杂）。

这篇论文（CUHK / MiuLar Lab / MMLab / PKU / Shanghai AI Lab，2025）对 DPO 与 GRPO 做了首次系统性对比研究，回答三个问题：

1. **范式对比**：域内（in-domain）表现和域外（out-of-domain）泛化，谁强谁弱？
2. **奖励模型的影响**：换不同的奖励模型，对两个算法的影响是否不同？
3. **扩展策略**：采样扩展、数据扩展、迭代训练，对两者各有什么效果？

## 他们怎么做的？

**试验设定**

- 任务：自回归图像生成（文本条件生成图像），生成序列视为 CoT 推理过程；
- 两个算法各自独立训练：DPO（离线偏好对）+ GRPO（在线组采样、组内相对优势）；
- 奖励模型备选四种：**HPS、ImageReward、Unified Reward、Hard Reward**（有强有弱、有生成式有判别式），用于给生成结果打分/构造偏好。

**三个维度的系统实验**

1. **范式对比**：同一数据、同一奖励模型下，分别用 DPO 和 GRPO 训练，测域内性能（训练分布内的任务与组合）与域外泛化（未见过的任务/组合，如颜色—形状—纹理—空间—非空间等属性组合的泛化）；
2. **奖励模型影响**：固定算法、逐个换奖励模型，看各算法性能对奖励模型选择的敏感度；
3. **扩展策略**：分别做采样扩展（同一数据多采样）、数据扩展（增加域内数据）、迭代训练（多轮），观察各自收益曲线。

## 效果怎么样？

**核心发现（四点）**

1. **DPO 域内更强，GRPO 域外泛化更好**——两者各有优势，不是简单替代关系；
2. **DPO 的泛化对奖励模型选择更敏感**：奖励模型自身泛化能力越强，RL 算法（尤其 DPO）的泛化潜力越大——奖励模型质量是 RL 泛化的关键杠杆；
3. **扩展策略效果不同**：
   - 采样扩展：对 GRPO 的域内收益最划算；
   - 数据扩展：提升 GRPO 泛化，但收益递减；
   - 迭代训练：最大化 DPO 的域内增益，但会牺牲泛化；
4. **过度采样有代价**：适度采样提升 DPO，过度采样引入偏好偏差（bias）。

## 对谁有用？

- 选 RL 算法的人：如果你的目标主要在域内刷分，DPO 更直接；如果要泛化到分布外（组合推理尤其如此——训练里见不到的属性—关系组合），GRPO 的在线组采样更稳；
- 写综述/做组合推理的人：这篇提供了"**为什么组合推理方法普遍以 GRPO 为底座**"的实证依据——域外泛化 + 对规则/结构化奖励的兼容性，正好是正文 2.2 对位段引用的对比结论来源；同时也提示：奖励模型自身能力是决定 RL 泛化的隐藏变量。

# Self-Questioning Vision-Language Models: Reinforcement Learning for Compositional Visual Reasoning

> 自我提问式 VLM：用强化学习训练模型"自己问自己"来完成组合视觉推理（MIT，2026）

## 这篇论文到底在解决什么问题？

**VLM 做组合视觉推理（比如"数出红色方块的数量，再和蓝色圆形的数量比较大小"）经常失败**。原因是：模型一次前向传播就直接出答案——看到图和问题，立刻输出结果，中间没有任何显式的分解过程。

为什么以前的方法不行？

- 让模型做多步推理的常规做法是训练它模仿**人工写的逐步解释**（human-written step-by-step explanations），但这些标注**贵、难扩展**；
- 强模型（GPT-4V 等）能"隐性"分解，但小模型没有这种能力，且隐性分解不可验证。

这篇论文想证明：**不用给任何分解示例，只用奖励信号（输出格式 + 最终答案正确），让模型自己"发明"出自我提问（self-questioning）的分解策略。**

## 他们怎么做的？

**核心 idea：定义一个"自我提问"输出格式 + 一个极简的 +1/−1 奖励（格式合规 且 最终答案正确），让 GRPO 自己把分解行为逼出来——全程不给任何分解示例。** 技术流派：GRPO 强化学习 + 奖励重设计（把"分解结构"本身变成训练目标）。

### 第一步：定义输出格式

模型输出必须是结构化序列：

$$ y = [\text{SQ}_1, \text{SA}_1, \ldots, \text{SQ}_k, \text{SA}_k, \text{FA}] $$

其中 SQ_i / SA_i 是第 i 个子问题/子答案，k（子问题数量）由模型自己决定，FA 是最终答案。System prompt 只给指令（"回答问题前先生成一系列子问题帮你看图，每个子问题看图给出答案，最后给最终答案"），**故意不给任何示例**——因为示例会让模型模仿特定分解模式，而不是自己探索。

### 第二步：奖励函数（极简二元）

$$ R(y, a^*) = \begin{cases} 1.0 & \text{if Format}(y) \land \text{Correct}(y, a^*) \\ -1.0 & \text{otherwise} \end{cases} $$

- **Format(y)**：至少有一对 "Sub-question / Answer"（标签匹配）；
- **Correct(y, a*)**：**containment 匹配**——归一化后的 GT 答案必须是归一化后预测的子串（大小写不敏感）。

两个关键设计：**不检查子问题本身的质量**（模型自己探索该问什么）；**格式和答案必须同时满足才给正奖励**——分解结构本身成为训练目标的一部分，这与只奖励最终答案的 RLVR 方法不同。

### 第三步：GRPO 训练

选 GRPO 而不是 PPO：GRPO 不需要单独的 value network，内存需求减半，适合有限 GPU。对每个 prompt (I, q) 采样 G 个完成，组内归一化优势：

$$ \hat{A}_i = \frac{R(y_i, a^*) - \mu_g}{\sigma_g} $$

策略更新带 KL 惩罚 β·D_KL(π_θ ∥ π_ref)，防止灾难性遗忘（模型可能在子问题格式上变好，但丢失底层视觉/语言能力）。

**参数高效微调（LoRA）**：冻结全部权重，只训练 q_proj / v_proj 的低秩适配器——rank r=16、α=32、dropout 0.05，更新参数 < 1%，48GB GPU 就能跑（全量微调会超显存）。

### 基线：Direct RLVR

为了隔离"自我提问"和"纯 RL"各自的贡献，训练一个对照模型：同样的 GRPO 流程、同样的超参数和数据，但 prompt 只要直接答案、奖励只查答案正确性和简洁性、无格式要求。两个模型唯一的差别就是自我提问格式——任何性能差都归因于格式本身。

### 训练配置

- **基座**：Qwen2.5-VL-3B-Instruct（3B，小模型便于在有限算力上跑 RL）；
- **数据**：CLEVR 10,000 例子集（合成几何场景、组合问题、可程序化验证）+ A-OKVQA 10,000 例子集（真实照片、需外部知识的开放 VQA）——一个测"能否学会分解"，一个测"能否泛化到真实域"；
- **训练**：G=8、约 7,000 步；
- **评测**：每个 benchmark 验证集 500 例，direct-answer 模式（子串匹配判定正确）。

### 与同类方法的区别

和 DeepSeek-R1 同属 GRPO 流程，但有两点不同：(1) 多模态——子问题生成时必须真正看图；(2) 奖励要求结构化的子问题-答案对格式，而不是自由形式 CoT——作者假设强制分解比自由 CoT 更能提升组合推理。

## 效果怎么样？

- **A-OKVQA 上 52.2% vs 未训练模型 46.8%**（标准 RL 是 51.6%）——自我提问略优于标准 RL，都大幅超基线；
- 在 CLEVR 合成场景上模型学会了分解策略，并且**能迁移到真实照片域**（训练一个域、测试另一个域也能提升）；
- 展示了"分解行为"可以涌现：模型从没被教过怎么分解，纯靠奖励自己问出了合理的子问题序列。

**局限性**：奖励只看格式和最终答案，**不验证子问题内容**——模型可能问废话问题糊弄格式；3B 小模型增益有限（52.2% 仍远低于大模型）；单作者 MIT 工作，规模较小，需要更多基座和基准验证。

## 对谁有用？

- 做**组合视觉推理、问题分解**的人——"让模型自己学会分解"的最直接实验证据；
- 做**RLVR 奖励设计**的人——演示了"格式+答案"极简奖励也能涌现结构化推理行为；
- 写综述时它是"推理过程优化"方向的核心文献：优化的对象从"答案"变成了"推理过程的结构（自我提问）"——奖励信号向推理过程对齐的典型代表。
